# מצגת תהליך רישוי משאיות — סקניה (PDI)

מצגת אינטראקטיבית, דף אחד, React, בעברית מלאה וכיוון RTL.
מיועדת **למשאיות בלבד**.

## תכונות

- 10 שקופיות: כותרת, שישה שלבי תהליך (א–ו), ושלושה נספחים (אנשי קשר, נתוני סוסים, משימות פתוחות).
- מעבר אופקי בין שקופיות, עם אנימציה.
- ניווט: חצים במקלדת (`←`/`→`, וגם `Space` / `PageUp` / `PageDown` / `Home` / `End`), כפתורי חצים, נקודות מחוון, והחלקה במגע.
- מחוון מספר שקופית ופס התקדמות.
- פלטת צבעים כהה ומינימלית, טיפוגרפיה גדולה וקריאה.

## מבנה

| קובץ | תיאור |
|------|-------|
| `index.html` | הפלט הבנוי, עצמאי לחלוטין (React מוטמע, ללא תלות רשת). **זה הקובץ שנפרס.** |
| `index.src.html` | קוד המקור הקריא — React + JSX. **את השינויים עורכים כאן.** |
| `build.js` | מהדר את ה־JSX ומטמיע את React לתוך `index.html`. |
| `vercel.json` | הגדרות פריסה ל־Vercel (אתר סטטי). |

## עריכה ובנייה מחדש

```bash
npm install
npm run build
```

עריכת התוכן/העיצוב נעשית ב־`index.src.html`, ואז `npm run build` מייצר מחדש את `index.html`.

## פריסה

האתר סטטי — `index.html` בשורש. אפשר לפרוס ל־Vercel ישירות (ללא שלב בנייה בענן),
או לכל אחסון סטטי אחר.
